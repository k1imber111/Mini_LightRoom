# Mini LightRoom

Локальный проявщик RAW (Sony ARW, Canon CR2/CR3, Nikon NEF, DNG и другие, а также JPEG) для Windows на Python и PySide6.
Всё считается на вашем компьютере, фото никуда не отправляются. Исходные файлы программа не меняет:
правки лежат рядом со снимками в `.mini_lightroom.json`.

Главное, чем программа отличается от обычных проявщиков:

- **Автокадрирование по правилам композиции.** Выбираете правило (золотое сечение, трети, спираль, треугольник,
  диагонали…) — кадр на экране сразу перекадрирован под него. Без подтверждений. Главный объект находится сам.
- **Отбор брака.** Расфокус, смаз и закрытые глаза ищутся в фоне, а программа показывает крупно, где именно брак.
- **Перенос стиля с чужого фото**, ИИ-цветокоррекция по «законам фотографии», маски, ретушь, шумодав.

## Автокадрирование по правилам композиции

Откройте кадр, нажмите **C** (обрезка) и выбирайте правило:

| Как выбрать | Что произойдёт |
|---|---|
| список «Сетка» в панели, клавиша **O** или стрелки **← →** | рамка сразу встаёт по выбранному правилу |
| листаете кадры (**↑ ↓**) | остаётесь в режиме: следующий кадр тоже кадрируется сразу |
| другая пропорция (3:2, 4:5, 1:1, 16:9…) | кадр заново строится под правило в этой пропорции |
| **Shift+O** | зеркало спирали или треугольника |
| **Enter** | выйти из обрезки (кадр уже обрезан, подтверждать нечего); **Esc** — вернуть как было |

Правила: **трети**, **золотая сетка** (38,2% / 61,8%), **золотая спираль**, **золотой треугольник**,
**диагонали**, **симметрия**, **квадратная сетка**. У каждого свои силовые точки (пересечения линий сетки), и
главный объект ставится на них. Формат кадра не меняется, меняется только размер и положение рамки.

**Как программа находит главное.** Каскад: лицо (глаза и куда смотрит человек) → человек → предмет
(птица и звери, корабль, самолёт, машина, башня, цветок…, сегментация SegFormer) → изолированное яркое пятно
(луна) или пересвеченный диск (закатное солнце). Горизонт ищется по границе неба. Лицо не режется, перед взглядом
остаётся место, запас над головой 4–16%, горизонт уходит с середины на линию правила.

**Если главное не найдено** (горы, город, облака) — программа так и говорит, показывает подсказку над кадром и
ждёт щелчка: вы указываете точку, и кадр строится вокруг неё. Точка запоминается для кадра; кнопка
«Сброс точки» возвращает автопоиск, «Указать главное» — выбрать заново, **Esc** — отменить выбор.

Дополнительно кнопка «Авто-кадр по композиции» (**Shift+C**) показывает до пяти лучших вариантов из всех правил
каруселью под кадром с оценкой и причиной. Автокадрирование выключается галочкой в панели. Веса оценки по жанрам
и предпочтения правил — в `composition.json`.

## Отбор брака

После открытия папки в фоне проверяется каждый кадр (кнопка «Фокус», **Ctrl+Shift+F**, пересчитает заново):

- **Расфокус и смаз.** Ширина размытия краёв по энергии градиента на полном разрешении (встроенный в RAW JPEG
  у Sony полноразмерный). Закат, небо и луна не бракуются; резкий объект на размытом фоне (боке) — не брак.
  Смаз отличается от расфокуса направлением, оно показывается стрелкой.
- **Где должно быть резко** решается по лицу, без лица — по точке автофокуса камеры (Sony) или по лучшим местам кадра.
- **Закрытые глаза** (MediaPipe): отдельно левый и правый.

В ленте — фильтры «Все / Брак / Сомнит. / Резкие» со счётчиками и значки на миниатюрах. Под фото — полоса
«Контроль качества»: статус, причина и плитки с крупным (100%) местом брака, рядом самое резкое место кадра для
сравнения; щелчок по плитке приближает кадр. На самом кадре место брака обведено.
**X** — брак, **U** — оставить (ваше решение важнее автоматического). Кнопка «В корзину (N)…» показывает
список и отправляет файлы **в корзину Windows** только после вашего подтверждения. Пороги — в `quality.json`.

## Остальные возможности

**Проявка и правки.** Экспозиция, контраст, света, тени, чёткость, температура, оттенок, сочность, насыщенность,
резкость, виньетка, тональная кривая (RGB/R/G/B), HSL по 8 цветам, обрезка и горизонт (±45°). Пока тянете
ползунок, кадр считается уменьшенным и обновляется в разы быстрее, полный дорисовывается через 0,2 с. Масштаб до 1600%
с дорисовкой полного разрешения. Отмена и повтор по каждому кадру (история сохраняется между запусками).
«Авто» подбирает тон и баланс белого.

**Стиль с референса (главная идея).** Выбираете чужой снимок — его цвет и настроение переносятся на ваши кадры.
Мягкий и точный (по распределениям L/a/b) режимы, раздельные силы цвета и света, защита кожи, смесь двух стилей,
LUT `.cube` для Lightroom, DaVinci и телефона.

**ИИ (локально, нужна видеокарта NVIDIA для комфортной скорости).**
- *ИИ-цветокоррекция*: цвета памяти (кожа, небо, зелень, вода), гармонии цветового круга, 60-30-10, карусель
  вариантов под кадром; **ИИ-улучшить** (**Shift+A**) одной кнопкой.
- *Маски*: кисть, линейный и радиальный градиенты, маски по содержимому (небо, люди, зелень, вода, здания, предметы);
  у каждой свои ползунки.
- *Ретушь кожи*, *размытие фона*, *шумодав* SCUNet (сам включается по ISO), *увеличение* Real-ESRGAN ×2/×4 при экспорте.
- *Сцены* (CLIP): закат, портрет, лес, ночной город и др.; пресет по сцене применяется к «Авто».
- *Единый цвет серии* (**Ctrl+Shift+M**): подгоняет выделенные кадры под эталон.

**Пресеты.** 28 готовых образов (`looks/*.json`) и свои (`presets/`). **Экспорт** в JPEG пакетом, можно
пропускать брак. **Память сессии**: программа открывается на том кадре, где вы остановились.

**Интерфейс.** Нейтрально-серая тема без оттенка (цвет вокруг снимка не искажает восприятие цвета самого снимка),
один акцентный цвет, скруглённые кнопки, линейные иконки, сворачиваемые группы панели, плавные анимации (отключаются
галочкой; по умолчанию как в настройках Windows).

## Установка

Нужны Windows 10/11 и Python 3.12.

1. Скачайте репозиторий и запустите **`start.bat`**: при первом запуске он сам создаст окружение `.venv` и поставит
   библиотеки. Вручную: `py -3.12 -m venv .venv`, `.venv\Scripts\pip install -r requirements.txt`,
   затем `.venv\Scripts\python.exe main.py [папка_со_снимками]`.
2. Для ИИ-функций (сцены, маски, ретушь, шумодав, увеличение, автопоиск предметов, лица и закрытые глаза) один раз
   запустите **`install_ai.bat`**: PyTorch с CUDA (около 3 ГБ), transformers, spandrel, mediapipe. Веса моделей
   скачиваются в `models/` при первом использовании. Без ИИ-библиотек остальное работает.

Видеокарта: проверялось на RTX 4060 Laptop (8 ГБ). Без CUDA ИИ-функции работают на процессоре, но медленно.

## Устройство

```
main.py                 точка входа (журнал падений и зависаний в logs/)
mini_lightroom/
  engine.py             проявка без Qt: правки, стиль, LUT, обрезка, экспорт
  ui.py                 окно PySide6; фоновые задачи, ИИ — только в одном потоке (AI_POOL)
  composition.py        автокадрирование: правила, поиск главного, оценка (без Qt)
  crop_editor.py, crop_overlays.py   рамка обрезки и геометрия сеток
  quality.py, faces.py, quality_ui.py   отбор брака, лица и глаза, интерфейс отбора
  segment.py, scene.py, grading.py, enhance.py   ИИ: сегментация, сцены, цвет, шумодав
  theme.py, widgets.py  тема, иконки, анимации
looks/ scenes.json composition.json quality.json   данные: пресеты, сцены, веса и пороги
tests/                  проверки (обычные скрипты)
```

Исходники RAW не меняются. Удаление возможно только отбракованных кадров, только в корзину Windows и только
после подтверждения в диалоге.

## Проверка

Тесты — обычные скрипты на `assert`, каждый запускается отдельно и печатает `OK`:

```
.venv\Scripts\python.exe tests\test_engine.py
.venv\Scripts\python.exe tests\test_composition.py     # правила, поиск главного
.venv\Scripts\python.exe tests\test_quality.py         # расфокус, смаз, боке
.venv\Scripts\python.exe tests\test_ui_autorule.py     # автокадрирование в окне
.venv\Scripts\python.exe tests\test_ui_cull.py         # отбор брака, корзина (на копиях)
.venv\Scripts\python.exe tests\test_ui_monkey.py 300 1 # случайные действия
.venv\Scripts\ruff.exe check --line-length 120 mini_lightroom
```

Окно проверяется в `QT_QPA_PLATFORM=offscreen`. `tests\test_real_raw.py путь\к\снимку.ARW` — замеры на настоящем RAW.
