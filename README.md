# Mini LightRoom

Личный проявщик RAW (Sony ARW и другие) для Windows. Работает полностью локально.

## Запуск
Двойной щелчок по `start.bat`. При первом запуске он сам создаст окружение и поставит библиотеки.
Вручную: `.venv\Scripts\python.exe main.py [папка_со_снимками]`.

## Что умеет
- **Лента кадров** слева: миниатюры из встроенного в RAW JPEG, мгновенно.
- **Поиск размытых кадров**: подозрительные помечаются ⚠, при экспорте их можно пропустить.
- **Правки**: экспозиция, контраст, света, тени, чёткость, температура, оттенок, сочность, насыщенность, резкость, виньетка. Шкалы широкие (экспозиция ±5 EV, остальное до ±200), двойной щелчок по ползунку сбрасывает его.
- **Масштаб**: от «вписать» до 1600% (25, 50, 75, 100, 150, 200, 300, 400, 500, 700, 1000, 1600). Проценты считаются от полного разрешения снимка; при приближении видимая часть дорисовывается в полном разрешении с правками. Колёсико приближает к курсору, перетаскивание двигает кадр, двойной щелчок по кадру — 100% / вписать.
- **Авто** подбирает тон и баланс белого под каждый кадр. Галочка «Авто для новых кадров» делает это при открытии.
- **Стиль с референса**: «＋ Новый стиль из фото…» → выбираешь чужой снимок → его цвет и настроение переносятся на твои кадры. Стили копятся в папке `styles`.
- **LUT (.cube)**: текущий цвет и стиль сохраняются в файл для Lightroom, DaVinci, телефона.
- **Пресеты** (28 готовых): мягкие пастельные образы с плавными кривыми, тонированием теней и светов и HSL. Сгруппированы по сценам: закат и рассвет, плёнка (Fuji 400H, Portra), портрет, город, ночь, природа. Часть сделана в духе известных фотографов: Хосе Вилья, Сол Лейтер, Джоэл Мейеровиц, Ринко Кавауси, Элизабет Мессина, Брэндон Вулфел, Стивен Шор. В списке у каждого пресета миниатюра вашего кадра. Ползунок «Сила пресета» плавно ослабляет образ. Пресеты лежат в `looks/*.json`, свои можно добавить туда же (формат как в `looks/builtin.json`).
- **Сцены (ИИ, локально)**: кнопка «🔍 Сцены» распознаёт каждый кадр: закат, сумерки, ночной город, портрет, люди, пейзаж, лес, море, снег, туман, цветы, город, архитектура, интерьер/еда. Сцена видна в ленте. С галочкой «Пресет по сцене» кнопка «Авто» и новые кадры получают пресет своей сцены. В экспорте есть пункт «Пресет по сцене для каждого кадра». Сцены описаны в `scenes.json`, там же меняются пресет и поправки для каждой сцены. Нужны библиотеки ИИ: один раз запустить `install_ai.bat` (PyTorch, ≈3 ГБ). Модель (≈600 МБ) скачивается при первом нажатии в папку `models`, фото никуда не отправляются.
- **Мои пресеты**: сохранить и применить свой набор правок (папка `presets`).
- **Пакетный экспорт** в JPEG: текущий, выделенные или все кадры; опция «Авто-тон для каждого кадра» подстраивает свет под каждый снимок, а стиль оставляет общий.
- Правки кадров хранятся рядом со снимками в `.mini_lightroom.json`, исходники не меняются.

## Горячие клавиши
| Клавиша | Действие |
|---|---|
| Ctrl+O | открыть папку |
| A | авто |
| \ | до / после |
| Ctrl+C / Ctrl+V | копировать правки / вставить в выделенные |
| Ctrl+R | сбросить правки |
| Ctrl+E | экспорт |
| Ctrl+= / Ctrl+- | крупнее / мельче |
| Ctrl+0 / Ctrl+1 | вписать / 100% |
| Ctrl+Shift+S | определить сцены |
| ↑ ↓ | следующий / предыдущий кадр |

## Проверка
```
.venv\Scripts\python.exe tests\test_engine.py
.venv\Scripts\python.exe tests\test_ui_smoke.py
.venv\Scripts\python.exe tests\test_real_raw.py путь\к\снимку.ARW
```
